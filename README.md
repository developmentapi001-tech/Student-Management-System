# Student Management System

A desktop-based Student Management System built using Python, Tkinter and SQLite.

##Project Screenshot

![Student Management System Dashboard]
(dashboard.jpeg)

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Total Students Count
- Total Courses Count
- Recent Students Dashboard
- SQLite Database
- Professional GUI Dashboard

## Technologies Used

- Python
- Tkinter
- SQLite
- SQL

## Purpose

This project was created to practice Python programming, GUI development, SQL and database management. It also demonstrates how a desktop-based Student Management System can be developed using Python and SQLite.
